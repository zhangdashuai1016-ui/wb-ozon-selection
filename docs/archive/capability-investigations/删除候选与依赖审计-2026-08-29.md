# 删除候选与依赖审计（2026-08-29）

结论：当前没有任何一项达到“可以直接删除”的证据门槛。本文件只登记调用关系、风险和删除前提，不授权删除、迁移、接线、运行脚本、启动服务、部署或访问外部平台。

## 1. 删除证据等级

| 等级 | 含义 | 当前动作 |
|---|---|---|
| A 可提交主人删除确认 | 已证明无源码、UI、启动器、运行副本和外部消费者；替代能力已验收；历史来源仍可追溯 | 由主人对精确路径确认后才能删除 |
| B 先迁移消费者 | 仍被当前源码、UI、测试、运行副本或历史数据语义依赖 | 不能删除，先设计并验证迁移 |
| C 只读归档 | 正常启动链已隔离，但源码仍可误运行，或必须长期保留来源 | 禁止运行；可在另行授权后移入不可执行代码档案 |
| D 正式保留／待比较 | 仍是当前能力、诊断工具、模拟器或选主候选 | 不是删除候选 |
| E 证据未知 | 仓库未找到调用，但外部人工、旧shell、CI或LaunchAgent消费者未核清 | 保持不动，继续核查 |

本轮A级数量：**0**。

1. 明确精确文件、接口、数据和运行副本范围。
2. 证明新的正式能力已经覆盖需要保留的职责。
