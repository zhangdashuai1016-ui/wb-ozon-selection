# 未来一周选品分工（2026-08-04）

## 统一三段边界

| 阶段 | 检查内容 | 结论边界 |
|---|---|---|
| A 方向与供应方案 | 目标平台市场、跨境份额（蛋蛋鼠主动研究≥40%）、市场体量/趋势、市场价格与初步正采购空间；随后锁定精确供应链接、具体供应SKU、商品价格、国内运费、实际采购成本、重量和尺寸，并由主人确认供应方案 | 方向不成立时可停止；方向可继续但供应资料未齐时留在A补资料。未确认供应方案不得进入B；IP/品牌异常转“需主人确认”，不自动淘汰方向 |
| B 具体SKU利润核算 | A阶段冻结的销售快照、主人确认的供应SKU和成本/包装数据、当前佣金、GUOO/CEL与汇率证据 | 不重新访问销售或供应平台，不重新找货或询问已有字段；直接给出目标平台独立利润结论 |
| C 采购/上架前来源与合规核验 | 对A阶段已确认的精确货源与SKU做一致性复核，并核验权利/IP、合规、带电/电池、最终包装属性 | C只核验、不重新寻找或替换供应方案。发现不一致时阻止当前SKU采购/上架并退回A重新确认，不淘汰方向；IP/品牌风险未经确认和权利核验，不得可上架/写店 |

## 蛋蛋鼠

1. 节日、季节和趋势仅作为进入Seerfar研究的入口，不直接生成候选。
2. 先取得目标Ozon市场折后成交价、跨境商品份额（门槛≥40%）、当前类目/方案佣金和实际可行的包装物流档。
3. 先反算采购到手总价的正空间；没有正采购空间的方向直接停止，不进入用户待确认。
4. 只在正利润方向内寻找具体SKU；在A阶段保存精确供应链接、具体SKU、商品价格、国内运费、实际采购成本、实包重量和尺寸并取得主人确认，再交给B计算。C阶段只复核来源一致性与权利风险，不重新找货。
5. 促销20%–30%只用于反推建议标价，禁止从折后成交价再次扣除。默认自然流量，广告成本按0；有真实投放计划再独立计算。
6. 不自动重试、不后台空转。技术失败做一次有证据的修复尝试；仍失败即停止并报告总控。

## Miska

1. 2026-08-04至2026-08-11只审核用户主动提交品，不主动扩散或自动新增方向。
2. 用户提交商品后，A阶段先取得并冻结Ozon目标市场销售快照，再保存精确供应链接、具体供应SKU、商品价格、国内运费、实际采购成本、打包重量和尺寸，由主人一次确认供应方案。
3. 供应资料未齐时停留在A补资料；主人确认供应方案后，B只读取冻结数据和当前费用证据计算利润，不重新打开供应商页。C阶段仅复核精确SKU、权利/IP、合规、带电和最终包装一致性。
4. 利润通过且基本风险清楚则进入待上架；不通过则淘汰；市场、佣金或物流证据不足时停止并报告总控。
5. 第一轮扩散至少需要5个完整、独立、利润通过并进入待上架的用户结构样本。同一商品的颜色、尺寸等变体只算1个结构样本。
6. 样本必须能归纳出至少1个可检验的共同经济结构，例如价格带＋包装物流档＋材质/用途；否则继续积累，不扩散。
7. 达标后只提交1份共同点假设和最多3条Seerfar验证方向给总控/用户确认；未经确认不得新增Miska候选。

## 共同边界

- Ozon与WB市场、佣金和物流证据各自独立，不能互相替代。
- 采购价固定表示货价＋国内运费的到手总成本，不拆分、不重复询问国内运费。
- 当前自动领取、定时重试和巡检保持暂停；任何重新开始须总控明确指令。

## 防空跑门禁

- “运行中”必须同时存在 `runId`、`startedAt`、`currentStep`、`lastProgressAt`；缺一项即状态异常，不占运行槽。
- 每轮必须产生状态变化、新证据或明确阻塞。健康检查、读取相同队列、重复保存同一证据都不算进展，也不产生用户可见消息。
- 同一候选、同一轮、同一证据层和同一目标只允许一次真实读取；重复尝试直接拒绝，不再打开浏览器。
- 一次有明确证据的技术失败后立即转“已停止待总控确认”，设置 `manualHold`；不再写 `deferred`，不再到点重领，也不把超时任务重新排队。
- 15分钟没有实质进展即停止本轮，只生成一条去重后的总控提醒。只有总控明确指定恢复路径后才能开始新一轮。
- 本规则只影响评审台研究与结论，不授权任何Ozon/WB店铺写入。
