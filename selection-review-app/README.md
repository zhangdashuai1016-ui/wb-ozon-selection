# 选品评审台应用源码

本目录属于未完成源码预览，范围与安全边界见[项目说明](../README.md)，不是开箱即用的生产安装包。

- src/：React 页面、组件与只读状态投影。
- lib/：领域规则、作业、存储边界和外部适配器源码。
- schema/：跨阶段输入、状态与授权合同。
- server.mjs：HTTP 与运行时接线入口，本次未执行。
- extension/1688-capture/：受控浏览器采集扩展，本次未加载。
- tests/：现有测试，部分依赖本地数据或临时服务，不能直接当作纯测试执行。
- scripts/：开发与既有 CI 支持代码，个人部署和启动配置不公开。

依赖清单、锁文件与工作区配置来自同一开发快照。前端使用 React/Vite，Node.js 服务和外部适配器仍需独立配置与隔离验证。不要用旧主分支依赖文件覆盖本目录，也不要把测试样例当作真实授权或正式证据。

动态 data/、经营证据、素材、能力快照和个人运行配置被排除，因此部分入口会明确失败。当前不承诺“直接启动即可完成 A→E”。先评审源码、识别接口与依赖缺口，再提交针对性修复。
